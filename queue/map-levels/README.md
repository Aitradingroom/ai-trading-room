# MAP Levels (TradingView, Pine Script v6)

A price map built from logarithmic round numbers (1–10, 20–100, 200–1000 …), halved again and again into mid-levels for lower timeframes. Use it as a structure for where price is likely to react.

Pine Editor → paste [`map_levels.pine`](map_levels.pine) → *Add to chart*.
